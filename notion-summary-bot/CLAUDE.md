# 議事録自動要約ボット

このディレクトリで `claude` を起動すると、Notionの議事録を自動で要約してくれます。

## 起動時にやること

以下の手順を自動で実行してください：

1. `node fetch-pages.js` を実行して未処理の議事録ページ一覧を取得する
2. 取得した各ページのトランスクリプト（`transcript`フィールド）を以下のフォーマットで要約する：

```
## タイトル
（Zoomやtldvのミーティングタイトルをそのまま記載）

## 部門 / 店舗
（トランスクリプトから参加者の部門または店舗名を読み取って記載。不明な場合は「不明」）

## 報告事項
（会議中に共有・報告された内容をすべて漏らず記載。箇条書き。誰が何を報告したかも含める）

## 決定事項
（会議で決まったことをすべて記載。箇条書き。決定に至った背景・理由も簡潔に添える）

## アクションリスト
（次にやるべきことを全件記載。箇条書き。担当者・期限が読み取れる場合は必ず含める）
```

3. 各ページに対して `node update-page.js <page_id> "<要約テキスト>"` を実行してNotionに書き戻す
4. 全ページの処理が終わったら「○件の議事録を要約しました」と報告する

## 要約のルール

- **内容を省かない**：トランスクリプトに含まれる情報はすべて反映する
- **誰が見ても伝わる文章**：会議に参加していない人が読んでも内容が理解できるよう、主語・背景・文脆を明確に書く
- **日本語で書く**：トランスクリプトが英語でも要約は日本語
- トランスクリプトが空のページはスキップする
- 1ページずつ順番に処理する
